# ATARA brand assets

Logo concept: a bold geometric house mark with a triangular roof opening and three structural uprights. The mark is drawn in dark burgundy brown and terracotta to match the supplied ATARA concept.

## Palette

- Primary brown: `#3A0B08`
- Terracotta: `#A65A3A`
- Warm background: `#F6EDE2`
- Supporting cream: `#F3E4D3`

## Typography

- Wordmark/headings: Manrope, semibold to bold, uppercase with generous tracking.
- Interface/body: DM Sans.

## Files

- `atara-mark.svg`: scalable transparent version of the supplied symbol for favicon and compact uses.
- `atara-mark-source-transparent.png`: background-removed raster source derived from the supplied image.
- `atara-logo.svg`: scalable horizontal brand lockup with PORTAL descriptor.
- `atara-mark-{64,128,256,512,1024}.png`: transparent square icon exports.
- `atara-logo-{360,720,1440}.png`: transparent horizontal logo exports.

Regenerate the PNGs from the SVG masters with `swift scripts/generate-branding.swift` from the repository root.
